What have we been focused on so far?

Where we’ve been investing

01

Making context & standards accessible to everyone

  • Self-serve troubleshooting with RAG AI and @help-engineering-bot
  • Documentation standards in Confluence and Backstage TechDocs, plus MCP connectors
  • Automatic code reviews with Bugbot, Security Reviewers, and Standards Enforcer
02

Improved quality for generated code

  • Skills, rules, and context written with best-known LLM practices in mind
  • Automatic self-validation with LLM-friendly instructions
  • Extreme code quality enforcement: linting, dead code detection, visual regression testing
03

Scaling up to handle increased volume & velocity

  • Faster local execution with a Rust-based toolchain
  • Reduced cost with smarter model defaults and education on model/effort behavior
  • Automatic code reviewer assignment and notification
